## Available Commands
```bash
# Initialize the system
~/openclaw/workspace-PA/skills/personal-health-tracker/health-tracker --init

# Add appointment
health-tracker add-appointment --type "Annual Physical" --date "2026-12-15" --time "10:00 AM" --location "Whitehall Family Medicine" --notes "Bring records"

# Add health metric
health-tracker add-metric --condition "Blood Pressure" --reading "Systolic" --value "120" --unit "mmHg" --date "2026-11-20"

# Add medication
health-tracker add-medication --name "Lisinopril" --dosage "10mg" --frequency "Daily" --start-date "2025-01-15"

# Add insurance
health-tracker add-insurance --provider "Blue Cross Blue Shield" --policy-number "BCBS123456" --effective-date "2025-01-01"

# Add emergency contact
health-tracker add-contact --name "Hailee Erickson" --phone "231-xxx-xxxx" --relationship "Spouse" --priority 1

# List appointments
health-tracker list-appointments

# List medications
health-tracker list-medications

# Sync calendar
health-tracker sync-calendar
```
