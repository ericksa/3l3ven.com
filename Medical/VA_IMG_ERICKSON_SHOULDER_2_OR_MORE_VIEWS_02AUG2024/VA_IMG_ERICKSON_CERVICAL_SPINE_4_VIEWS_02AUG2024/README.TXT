VA Medical Images and Reports
ReadMe

The My HealtheVet VA Medical Images and Reports feature allows you to:
  - view non-diagnostic thumbnail pictures of your medical images
  - view, print, and download a copy of your report
  - download a .zip file that contains a copy of your diagnostic quality images and your report

Here are a few tips for using this .zip file:

1. You can use the .zip file to share your medical images and report with another provider.  
   More information about how to copy your medical images and report to a flash drive or CD can 
   be found in the VA Medical Images and Reports User Guide.

2. All of your diagnostic quality images are located in the DICOM folder and have the file 
   extension *.dcm.  

3. Special software is needed to view these DICOM images.  For more information about this 
   software please read the VA Medical Images and Reports User Guide.

4. The DICOMDIR file is a directory file that other computer systems can use to document the 
   DICOM files that are included.

5. The Report.txt file is a copy of your report.  This is the same report that is available 
   in PDF or txt format when you click on the View button for a study.
