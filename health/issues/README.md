# Health Issues Log

Track all diagnosed health conditions, symptoms, and readings over time.

## Structure
- `conditions.md` - List of all diagnosed conditions
- `<condition>.md` - Individual condition tracking with timestamps
- `readings_over_time.md` - Chronological log of all health metrics

## Common Health Metrics to Track

- **Blood Pressure** - Systolic/Diastolic (mmHg)
- **Weight** - Pounds/Kilos
- **Blood Glucose** - mg/dL or mmol/L
- **A1C** - Percentage (every 3 months)
- **Cholesterol** - Total, LDL, HDL (mg/dL)
- **Temperature** - Fahrenheit/Centigrade
- **Heart Rate** - Beats per minute
- **Pain Scale** - 0-10 intensity

## Data Entry Format

```
## [Condition/Metric Name]
- **Date:** YYYY-MM-DD HH:MM
- **Value:** [Numeric value + unit]
- **Notes:** [Optional context]
```
