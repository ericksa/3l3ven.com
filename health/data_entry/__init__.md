# Health Data Entry - Initialization

This directory contains templates for entering health information.

## Getting Started

1. **Review your data** - Check existing files in:
   - `appointments/upcoming.md` - For scheduled visits
   - `issues/readings_over_time.md` - For health metrics
   - `medications/00_index.md` - For current prescriptions

2. **Use templates** - Start new entries with templates from this folder

3. **Sync calendar** - Run `health-tracker sync-calendar` after adding appointments
