# Health Readings Archive

This directory contains detailed reading logs organized by metric type.

## Files
- `blood_pressure.md` - Systolic/diastolic readings with pulse
- `weight.md` - Weight measurements over time
- `glucose.md` - Blood glucose readings
- `cholesterol.md` - Lipid panel results
- `temperature.md` - Body temperature logs
- `other.md` - Miscellaneous health measurements

## Format Template

```markdown
## [Metric Type] Readings

| Date | Time | Value | Units | Notes |
|------|------|-------|-------|-------|
| YYYY-MM-DD | HH:MM | Numeric | Unit | Observations |
```
